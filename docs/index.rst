Bloom documentation
===================

Bloom supports clinician-led speech therapy and Redmond Sentence Recall studies
with the M robot. Choose a guide based on what you need to do.

Run an RSR study
----------------

Start with :doc:`the RSR study guide <rsr-study>` for researcher login, robot
pairing, continuous recording, scoring, and reviewing study sessions.

Set up or develop Bloom
-----------------------

Use :doc:`platform setup </README>` to install and run Bloom,
:doc:`development <development>` for architecture and tests, or
:doc:`robot setup <robot-guide>` to connect and run M.
